# Fieldnotes UGC ad scripts

Creator-style drafts for introducing the Deep Research Agent. These are scripts and shot notes, not finished video ads. Keep the product footage authentic to the current app and review every factual claim before publishing.

## 1. “20 tabs open” — 20 seconds

**Format:** selfie camera, casual desk setup, screen recording insert of the real Fieldnotes homepage and a generated briefing.

**Hook (0–3s):** “Ever open 20 tabs for one question and still not know where to start?”

**Creator:** “I’ve been trying Fieldnotes. I put in a research question, add the angle I care about, and it gives me a briefing with findings, source links, evidence limits, and follow-up questions. I’m checking the original sources before I trust anything—but it gives me a much clearer place to begin.”

**On-screen CTA:** “Try a question · Check the sources”

**Footage:** show a real prompt in the app, click **Start research**, then scroll to the actual source list. Do not stage fabricated results.

## 2. “Start without API keys” — 15 seconds

**Format:** vertical selfie video with a brief, real screen capture.

**Hook (0–3s):** “Want to explore a topic before setting up AI keys?”

**Creator:** “Fieldnotes has a no-key source briefing mode. It searches public Wikipedia and Crossref records and organizes the excerpts into a research map. It isn’t an AI synthesis, so open the links and verify the claims yourself.”

**On-screen CTA:** “Explore Fieldnotes on GitHub”

**Footage:** select “No-key source briefing” in the current interface and show real returned sources. Avoid promising complete coverage.

## 3. “A question, then an angle” — 25 seconds

**Format:** creator at a laptop; use a real example question and the real angle field.

**Hook (0–3s):** “The trick is asking a better research question.”

**Creator:** “Instead of typing ‘batteries,’ I ask, ‘What limits sodium-ion batteries for grid storage?’ Then I add an angle: ‘manufacturing cost compared with lithium-ion.’ Fieldnotes returns a structured briefing and links to the sources it found. The app works with public-source mode, local Ollama, or OpenAI and Tavily when configured. I use it to get oriented, then read the sources myself.”

**On-screen CTA:** “Try a focused question · Star the repo if it helps”

**Footage:** show the prompt being entered, then the real briefing and sources. Keep API keys and environment variables off-screen.

## Creator notes

- Speak in your own voice; keep the tone curious and specific rather than claiming the tool is perfect.
- Show only the live app and real outputs. Do not add fake citations, source counts, or speed claims.
- Say “research starting point” or “source-grounded briefing,” not “verified answer.”
- Never show API keys. Use no-key mode for public demos, or use a test key stored only in the server environment.
- If a hosted or local model is used, name that mode accurately. No-key mode organizes source excerpts; it does not use an LLM to synthesize them.
