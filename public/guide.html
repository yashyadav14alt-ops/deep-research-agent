FIELD GUIDE · 3 MIN READ

From question
to a research map.

Fieldnotes helps you explore a topic, see where its starting sources came from, and decide what to investigate next. Treat the briefing as a map—not a final fact-check.

01 / START

Ask a focused question

  1. Open the research workspace.
  2. Enter a question with enough context to distinguish what you want to know. For example: “What limits the use of sodium-ion batteries for grid storage?”
  3. Use Optional angle to narrow it further, such as “manufacturing cost compared with lithium-ion”.
  4. Choose a research mode and select Start research.

Short, specific questions usually make it easier to judge whether each result is relevant. Try one angle at a time when a topic is broad.

02 / CHOOSE A MODE

Pick the right setup

Automatic
Uses OpenAI + Tavily if both API keys are configured; otherwise it uses the no-key source briefing.
No-key source briefing
Searches public Wikipedia and Crossref records and organizes the available excerpts. It does not generate an LLM synthesis.
Local Ollama model
Uses public-source results, then sends excerpts to your configured local Ollama server to draft the briefing.
OpenAI + Tavily
Uses Tavily to search and OpenAI to synthesize the returned excerpts. The server needs both API keys.

For setup instructions and environment variable names, see the project README.

03 / READ THE BRIEFING

Follow the evidence

  • Key findings and deep dive: scan the source-linked excerpts and model synthesis, if you chose an LLM mode.
  • Debates & evidence limits: note what the search could not establish.
  • Sources: open the original link. Check the publication date, methods, and whether the source supports the specific claim.
  • Open questions and related topics: use these to plan your next search.

Search results can be incomplete or outdated. This MVP reads search excerpts and scholarly metadata, not full webpages or papers, and it does not independently verify source claims. Do not treat a generated briefing as medical, legal, financial, or other professional advice.

A GOOD FIRST RUN

Question: How does urban tree cover affect summer heat in Indian cities?

Angle: evidence from satellite studies and limits of city-level comparisons

Mode: No-key source briefing to explore source leads, or OpenAI + Tavily / Ollama for a model-written synthesis.
